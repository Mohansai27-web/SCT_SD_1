Conversion Formulas

°C

Celsius → Fahrenheit

°F = (°C × 9/5) + 32

°F

Fahrenheit → Celsius

K

Celsius → Kelvin

K = °C + 273.15

K

Kelvin → Celsius

°C = K − 273.15

°C

Fahrenheit → Kelvin

K = (°F − 32) × 5/9 + 273.15

°F

Kelvin → Fahrenheit

°F = (K − 273.15) × 9/5 + 32

About The Project

Temperature Conversion Web Application

This web application is developed using HTML, CSS and JavaScript. It allows users to convert temperature values between Celsius, Fahrenheit and Kelvin scales.

The project includes a modern user interface, colourful headings, responsive design, animated 3D thermometer graphics and real-time temperature conversion.
