# SkillCraft Technology - Task 01: Temperature Conversion Program

This repository contains the solution for **Task 01** assigned by **SkillCraft Technology**. The objective of this project is to build a program that converts temperature values between **Celsius**, **Fahrenheit**, and **Kelvin** scales.

---

## 📌 Features

- **Bidirectional Conversions**: Converts any input temperature into the other two scales simultaneously.
- **Flexible Unit Selection**: Accepts inputs in Celsius (°C), Fahrenheit (°F), or Kelvin (K).
- **Input Validation**: Ensures valid numeric input and correct unit specifications.

---

## 🧮 Conversion Formulas

- **Celsius ($C$)**:
  - Fahrenheit: $F = (C \times \frac{9}{5}) + 32$
  - Kelvin: $K = C + 273.15$

- **Fahrenheit ($F$)**:
  - Celsius: $C = (F - 32) \times \frac{5}{9}$
  - Kelvin: $K = (F - 32) \times \frac{5}{9} + 273.15$

- **Kelvin ($K$)**:
  - Celsius: $C = K - 273.15$
  - Fahrenheit: $F = (K - 273.15) \times \frac{9}{5} + 32$
